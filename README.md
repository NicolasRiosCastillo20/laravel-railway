# ☕ Mocca Aventura y Café

## 📖 Descripción

Mocca Aventura y Café es una plataforma web desarrollada para promover experiencias turísticas, actividades de aventura y contenido relacionado con el turismo en el Quindío, Colombia.

La aplicación permite a los visitantes conocer los servicios ofrecidos por la empresa, explorar experiencias realizadas, consultar publicaciones del blog y contactar fácilmente a la organización para obtener información o reservar actividades.

Además, cuenta con un panel administrativo para la gestión de contenido, permitiendo mantener actualizada la información del sitio sin necesidad de conocimientos técnicos.

---

## 🎯 Objetivos del Proyecto

- Promover experiencias turísticas y actividades de aventura.
- Facilitar la difusión de contenido mediante un blog.
- Mejorar la presencia digital de la empresa.
- Centralizar la administración de servicios y publicaciones.
- Proporcionar una experiencia moderna y accesible para los usuarios.

## 🚀 Instalación

### Clonar el repositorio

```bash
git clone https://github.com/NicolasRiosCastillo20/laravel-railway
cd laravel-railway
```

### Instalar dependencias

```bash
composer install
```

### Configurar variables de entorno

```bash
cp .env.example .env
```

### Generar clave de aplicación

```bash
php artisan key:generate
```

### Ejecutar migraciones

```bash
php artisan migrate
```

### Iniciar servidor local

```bash
php artisan serve
```
